# Portfolio

Site personnel de présentation de projets et de compétences. Ce dépôt regroupe les pages, styles et scripts utilisés pour construire un portfolio web moderne.

## Aperçu
- Pages principales : accueil et pages de contenu
- Styles dédiés : `style/`
- Scripts : `script/`
- Ressources : `assets/`, `imgs/`, `files/`

## Utilisation
Ouvrez `index.html` dans votre navigateur pour consulter le site en local.

## Structure du projet
- `index.html` : page d’accueil
- `page.html` : page secondaire
- `style/` : feuilles de style CSS
- `script/` : scripts JavaScript
- `assets/`, `imgs/`, `files/` : ressources et médias

## Statut
Projet en évolution : le contenu et le design peuvent être mis à jour régulièrement.
